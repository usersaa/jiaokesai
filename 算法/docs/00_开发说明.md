# 00 开发说明

## 1. 项目定位

本项目是第三届甘肃省大学生交通运输科技大赛（硕士生 K 类）参赛作品的算法实现部分，研究对象为兰州交通大学校园共享电单车系统（7MA 出行，首批 500 辆）。

目标不是做一个"预测 + 调度"的演示 Demo，而是把建模文档中的完整链路落成**可运行、可复现、可扩展**的代码：

```
需求侧（七脉冲 + OD）
      ↓
供给侧（库存演化 + 可用率 + 作业时间）
      ↓
下层用户选择（移步 κ + 竞争取车 f + 激励）
      ↓
上层调度（MDP / PPO）+ 夜间静态 MILP
      ↓
评价指标（8 项）+ 基线 / 消融 / 敏感性 / 泛化
```

## 2. 当前状态（重要）

- **真实数据尚未采集**。`data/synthetic/` 中的 12 个 P 点、需求量级均为占位数据，仅用于跑通代码与自检。
- 所有待观测参数在 `configs/default.yaml` 中以 `[TODO]` 标注，采集后只改配置，不改代码。
- 已训练一个 20 万步 PPO 模型（`outputs/ppo/`），用于验证链路与给出占位结果；真实数据到位后需重新训练。

## 3. 环境与安装

- Python ≥ 3.10（本项目在 3.13 上验证）
- 依赖见 `requirements.txt`，核心为：`gymnasium`、`stable-baselines3`、`sb3-contrib`、`torch`、`ortools`、`pandas`、`pyyaml`

```bash
# 建议独立虚拟环境
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r requirements.txt
```

> 国内网络若访问 PyPI 超时，可使用镜像：
> `pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`

## 4. 快速运行

```bash
# 1) 生成占位数据（12 个 P 点 + 逐步需求 + 采集模板）
python scripts/make_synthetic_data.py

# 2) 冒烟训练（约 1 分钟）
python scripts/train_ppo.py --smoke

# 3) 正式训练（20 万步，CPU 约 5 分钟）
python scripts/train_ppo.py --timesteps 200000 --seed 0 --out outputs/ppo

# 4) 基线对比
python scripts/run_baselines.py

# 5) 主实验（含 SA 与 PPO）
python scripts/run_experiments.py --exp main --model outputs/ppo/ppo_seed0

# 6) 夜间 MILP
python scripts/run_night_milp.py

# 7) 单元测试
pytest
```

## 5. 目录约定

| 目录 | 职责 | 不做什么 |
|---|---|---|
| `configs/` | 唯一参数入口 | 不放代码 |
| `data/` | 输入数据与采集模板 | 不放模型、不放输出 |
| `src/bike_sched/` | 全部算法源码 | 不放脚本入口 |
| `scripts/` | 命令行入口 | 不写核心算法 |
| `tests/` | 单元测试 | 不做长时间训练 |
| `docs/` | 开发文档 | — |
| `web/` | 地图标定工具（独立前端） | 不参与 Python 训练 |
| `outputs/` | 训练产物、实验 CSV/PNG | 可删除重建 |

## 6. 开发约定

1. **参数不写死**：所有可调参数进 `configs/default.yaml`，代码中不出现魔法数字。
2. **可追溯**：每个模型要素在 `docs/01_建模说明.md` 中标注文献来源（L1–L5）或标为假设。
3. **数据缺失显式化**：占位值必须带 `[TODO]`，不得把占位结果当实证结论。
4. **测试先行**：修改需求/供给/环境后，先跑 `pytest`，再跑训练。
5. **不提交大数据**：`outputs/`、`data/real/` 不入库（如需入库请用 Git LFS）。

## 7. 与地图工具的关系

`web/` 是独立的 P 点标定地图（高德 JS API 2.0），用于采集 P 点坐标与容量：

1. 双击 `web/index.html`，用真实浏览器打开；
2. 「标定模式」点选 P 点，「导出 JSON」；
3. 将 JSON 转为 `data/real/stations.csv`（列定义见 `docs/03_数据字典与采集规范.md`）。

地图工具与算法解耦：算法只读 CSV，不依赖浏览器或高德 Key。

## 9. 已知限制

- 单辆运维车（`truck.count=1`）；多车需要扩展动作空间与信用分配。
- 搬运在当步末完成，忙碌时间用于限制后续调度；跨步在途的精确刻画列为扩展。
- 不刻画单车级电量，电量聚合为可用率 `ρ_soc`。
- 换电路线与搬运路线不做联合优化，换电以 `T_swap` 占用时间进入模型。
- 模拟退火基线扰动的是参数化贪心策略的参数，而非逐动作序列（详见 `docs/02_算法设计.md`）。
