## 2. 数据流

```
configs/default.yaml
        │ load_config()
        ▼
   cfg (dict)
        │
        ├── make_synthetic_scenario(cfg) 或 load_scenario_from_csv(cfg, path)
        ▼
   Scenario {stations, pulses, dist_m, cfg}
        │
        ├── DemandModel(cfg, sc)   → D_i(t), q_ij(t)
        ├── SupplyModel(cfg, sc)   → n_avail, borrow, return_shortage, τ
        ├── ChoiceModel(cfg, sc)   → κ, f, redirect
        ▼
   CampusEnv(cfg, sc)  ← Gymnasium
        │ reset() / step()
        ▼
   EpisodeMetrics → metrics_summary()
        │
        ├── MaskablePPO（训练/推理）
        ├── baselines（对照）
        └── scripts/run_experiments.py（汇总/作图）
```

## 3. 关键接口

### 3.1 配置

```python
from bike_sched.config import load_config, time_grid, n_steps, pulses_from_config

cfg = load_config("configs/default.yaml")
grid = time_grid(cfg)          # [390, 400, ..., 1400]（当日分钟）
T = n_steps(cfg)               # 102
```

### 3.2 场景

```python
from bike_sched.scenario import make_synthetic_scenario, load_scenario_from_csv

sc = make_synthetic_scenario(cfg)                  # 12 个占位点
sc = load_scenario_from_csv(cfg, "data/real/stations.csv")
sc.n                 # 站点数
sc.capacities        # np.ndarray (N,)
sc.init_inventory()  # np.ndarray (N,)
sc.dist_m            # np.ndarray (N,N) 米
```

### 3.3 模型

```python
from bike_sched.demand import DemandModel
from bike_sched.supply import SupplyModel
from bike_sched.choice import ChoiceModel

dm = DemandModel(cfg, sc)
D = dm.true_demand(step)            # (N,)
od = dm.od_matrix(D)                # (N,N)
P = dm.od_probabilities()           # (N,N)

sm = SupplyModel(cfg, sc)
avail = sm.available(inv)           # (N,)
b, e_b = sm.borrow(D, avail)
r = sm.returns(realized_od)
e_r = sm.return_shortage(r, free)
tau = sm.truck_service_min(i, j, q)

cm = ChoiceModel(cfg, sc)
extra, coupon_cost, M = cm.redirect(e_b, avail - b, D, prices)
```

### 3.4 环境

```python
from bike_sched.env import CampusEnv

env = CampusEnv(cfg, sc, seed=0)
obs, info = env.reset(seed=0, options={"day_type": 0})
mask = env.action_masks()           # 精确扁平掩码
obs, r, term, trunc, info = env.step(action)
metrics = env.metrics_summary()
```

### 3.5 PPO

```python
from bike_sched.rl.ppo import train_ppo, load_ppo
from bike_sched.rl.evaluate import PPOPolicy, evaluate_policy

model, env = train_ppo(cfg, sc, total_timesteps=200000, seed=0,
                       save_path="outputs/ppo/ppo_seed0")
model, env = load_ppo("outputs/ppo/ppo_seed0", cfg, sc)
policy = PPOPolicy(model)
rows = evaluate_policy(lambda: CampusEnv(cfg, sc, seed=0), policy, seeds=[101, 102, 103])
```

### 3.6 基线

```python
from bike_sched.baselines import NoOpPolicy, RandomPolicy, GreedyPolicy, SimulatedAnnealingPolicy

NoOpPolicy().act(env)
RandomPolicy(seed=0).act(env)
GreedyPolicy(allow_truck=True, allow_coupon=False, name="pure_truck").act(env)
sa = SimulatedAnnealingPolicy(lambda: CampusEnv(cfg, sc, seed=0))
sa.fit()
```

### 3.7 夜间 MILP

```python

res["y"]        # 各点净调入/调出

res["route"]    # 车场 → ... → 车场
```

## 4. 扩展点

### 4.1 增加/替换 P 点

1. 准备 `data/real/stations.csv`（列定义见 `docs/03`）；
2. 运行脚本时加 `--stations data/real/stations.csv`；
3. 代码无需修改。

### 4.2 增加新的功能类别

1. 在 `configs/default.yaml → demand.function_origin_intensity` 加一行；
2. 在 `demand.function_attraction` 加一行；
3. `Station.func` 使用新类别即可。

### 4.3 增加新的基线

1. 在 `src/bike_sched/baselines/` 新建类，实现 `act(env, obs=None) -> action`；
2. 在 `baselines/__init__.py` 导出；
3. 在 `scripts/run_experiments.py` 的 `build_policies` 中注册。

### 4.4 多辆运维车

当前 `truck.count=1`，环境会显式报错。扩展步骤：

1. `TruckState` 改为列表；
2. 动作空间增加"选择哪辆车"维度；
3. `step()` 逐车结算；
4. 奖励按车分解（L3 的信用分配思路）。

### 4.5 换电路线联合优化

1. 在 `SupplyModel.available_truck_min()` 中把 `T_swap` 改为按点位/时段的时间窗；
2. 在夜间 MILP 中加入换电任务约束；
3. 需要单车级电量数据。

### 4.6 多目标/约束 RL

当前用加权和。若需显式约束（如服务率 ≥ 99%），可改为：

- Lagrangian PPO：把约束乘子加入奖励；
- CPO / PPO-Lagrangian（需自定义）。

## 6. 代码约定

1. **类型标注**：公共函数带 `from __future__ import annotations` 与类型标注；
2. **无魔法数字**：参数从 `cfg` 读取；
3. **纯函数优先**：`demand/supply/choice` 不持有环境状态；
4. **环境可复现**：`reset(seed=...)` 控制需求噪声；
5. **不吞异常**：配置缺失/维度不符时显式报错；
6. **中文注释**：关键公式标注文献编号与式号。

## 7. 常见问题

### Q1：训练很慢？

- 12 点位 × 102 步，CPU 20 万步约 5 分钟；
- 若更慢，减小 `ppo.n_steps` / `net_arch`，或先用 `--smoke`。

### Q2：PPO 只学"不调度"？

- 检查奖励权重（`cost.weights`）：`w2` 太低会让 agent 吝啬搬运；
- 检查动作掩码：用 `discrete` 而非 `multidiscrete`；
- 增加训练步数（≥ 20 万）；
- 检查 `delta_critical` 是否过大/过小。

### Q3：服务率 100% 但短缺不为 0？

- 短缺含"还车短缺"（满位），服务率只统计借车；
- 看 `bike_shortage` 与 `return_shortage` 两个分量。

### Q4：夜间 MILP 不可行？

- 检查 `Σ capacity ≥ total_bikes`；
- 检查 `depot_station` 在 0..N−1；
- 放宽 `time_limit_s` 或检查 `truck.capacity`。

### Q5：换真实数据后结果很差？

- 先检查 `stations.csv` 的容量/初始库存是否合理；
- 用 `python scripts/run_baselines.py --skip-sa` 看 noop/greedy 是否合理；
- 再训练 PPO；
- 真实数据分布与占位数据不同，超参数需重调。
