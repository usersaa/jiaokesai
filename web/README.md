# 校园共享电单车 P 点标定地图（精简版）

兰州交通大学（安宁校区）P 点标定工具。只保留最基础的地图与标定功能。

## 文件

| 文件           | 说明                   |
| ------------ | -------------------- |
| `index.html` | 页面结构                 |
| `style.css`  | 样式                   |
| `config.js`  | 高德 Key、校区中心点、功能类别等配置 |
| `app.js`     | 地图初始化、标定、导入导出        |

## 使用

1. 直接双击 `index.html`，用浏览器打开（需联网加载高德地图）。
2. 点「标定模式」，在地图上点一下即新增一个 P 点，按提示填名称、容量。
3. 右侧列表可「编辑 / 删除」；数据自动存本地，刷新不丢。
4. 「导出 JSON」保存标定结果；「导入 JSON」可再次载入。

## 2D / 3D

高德 JS API 2.0 的 `viewMode` 是**初始化参数**，3D 必须创建时指定才会加载 WebGL 引擎。  
因此切换视图采用「销毁重建地图实例」的方式：2D 用真正的 2D 引擎、3D 用真正的 3D 引擎，  
切换时保留当前中心点与缩放级别。

## 配置

在 `config.js` 中修改：

- `AMAP_CONFIG.key` / `securityJsCode`：高德 Web 端 Key（注意域名白名单）
- `CAMPUS.center` / `zoom` / `pitch`：校区中心、初始缩放、3D 俯仰角
- `FUNC_TYPES`：点位功能类别与颜色
